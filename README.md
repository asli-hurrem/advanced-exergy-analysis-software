# Advanced Exergy Analysis Software

**Advanced Exergy Engine** is an advanced exergy analysis software and research workspace for traceable, reproducible thermodynamic and exergy-based studies.

The platform supports researchers who need to perform advanced exergy analysis with transparent scenario handling, validation, reproducibility, and publication-ready reporting.

Live public beta: https://aslitiktas.pythonanywhere.com/

## What It Does

Advanced Exergy Engine helps researchers:

- Build component-level thermodynamic models
- Import and manage thermodynamic state data
- Define REAL, IDEAL, and UNAVOIDABLE scenarios
- Register hybrid advanced-exergy runs
- Validate decomposition closure
- Track methodology context
- Export publication-ready advanced exergy results
- Generate reproducibility bundles for research transparency
